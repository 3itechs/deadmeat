# Dead Meat Society — CRO & Landing Page Proposal

Client-facing proposal and the first landing page design for
[deadmeatsociety.com](https://deadmeatsociety.com).

## Files

| File | What it is |
|---|---|
| `DMS-CRO-Proposal.html` | **Start here.** Conversion audit (12 findings), brand direction, six landing-page archetypes, the two-week sprint plan, and KPIs. |
| `DMS-Landing-Page-01.html` | LP-01 "The Cookout Test" — the advertorial landing page, designed in full. |

## How to view

Open `DMS-CRO-Proposal.html` in any browser. In Section 04 there is a button,
**Open the LP-01 design →**, which opens the landing page in a new tab.

> Both files must stay in the same folder — the button between them is a
> relative link.

## Process

Designs are built as **working HTML**, not Figma mockups. The client reviews a
real, responsive page on a link — on their own phone — and approves it. The
approved markup is then converted into native Shopify Liquid sections, so the
design that gets signed off is the same file that ships.

## Notes

- The landing page has a **CRO Notes** switch in the bottom-left corner. Turn it
  on and all nine conversion zones are highlighted with an explanation of what
  each one does and which audit finding it answers. It is a presentation aid and
  would not ship on the live page.
- Photography is marked with labelled placement slots carrying art direction
  (ratio, grade, subject). These double as the shot list.
- Fonts load from Google Fonts, so the pages need an internet connection to
  render exactly as designed.
- Pricing in Section 07 is intentionally left blank, to be filled in before the
  proposal is sent to the client.
